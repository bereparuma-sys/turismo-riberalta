# 🌴 Guía Turística de Riberalta

¡Bienvenido al repositorio oficial de la Guía Turística de Riberalta! Este proyecto tiene como objetivo promocionar los principales atractivos turísticos, hoteles y lugares de interés de la región.

## 🚀 Ver Sitio Web en Vivo
Puedes acceder a la versión publicada en el siguiente enlace:
👉 [https://bereparuma-sys.github.io/turismo-riberalta/public/](https://bereparuma-sys.github.io/turismo-riberalta/public/)

## 🛠️ Tecnologías Utilizadas
* **HTML5** - Estructura semántica de la web
* **CSS3** - Estilos visuales y diseño responsivo
* **JavaScript** - Lógica e interactividad
* **Node.js** - Entorno de desarrollo local

## 📂 Estructura del Proyecto
* `/public` - Contiene las imágenes, hojas de estilo y el archivo principal `index.html`.
* `index.js` - Configuración del servidor local.
